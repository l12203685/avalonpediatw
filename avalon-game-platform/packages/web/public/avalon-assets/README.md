# Avalon Assets

These 27 image files are **placeholder stubs** committed to the repo so
the frontend builds and runs out of the box.

The original artwork from *The Resistance: Avalon* is copyrighted by
**Indie Boards & Cards** and is **not redistributed** in this repository.

## Filenames

See `/ASSET_CREDITS.md` in the repository root for the full list of files
and their original meaning.

## Using the real artwork locally

If you legally own the board game and want to use scans of your own copy
for personal, non-commercial play, drop the files in this directory using
the same filenames. These filenames are listed in the project `.gitignore`
so they cannot be re-committed by accident.

## Future plan

We plan to commission original AI-generated artwork licensed under
