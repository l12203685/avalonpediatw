# 資訊不對稱與資訊熵研究規格 v0.1

## 研究問題與優先級

1. **R1｜任務選人效用**：給定資訊集與局勢，最大化成功率與資訊增益的隊伍是否相同？建立 Pareto frontier；再透過遞迴勝率函數測試實際效用。
2. **R2｜梅林資訊揭露**：對單一公共訊號，同時計算忠臣對紅方的熵減與刺客對梅林的熵減，以好人最終勝率為目標函數。
3. **R3｜欺瞞信念污染**：計算訊號的可靠性、來源信任與角色行動動機；預測「自信但錯誤」之風險，不能用熵減直接代表正確性。
4. **R4｜動態行為模型**：q 應為 q(role,mission,score,team_allies,history,player_style)，先以資料學習可解釋的分層模型，未校準前只跑敏感度。

## 數學模型

令 Z 表示完整身份配置、O 表示公開與合法私有的過往觀測、T 表示候選隊伍、Y 表示可觀測的失敗票張數。

- `P(Z|O) ∝ P(O|Z) P(Z)`；硬約束排除不可能的世界。
- `H(Z|O) = -Σ_z P(z|O) log2 P(z|O)`。
- `IG(T) = H(Y|O,T) - E_{Z|O}[H(Y|Z,O,T)]`，對候選結果平均的預期資訊增益。
- MVP 假設每名紅方以相同且獨立的 q 炸車：`Y|Z,T ~ Binomial(#Evil(Z,T), q)`。
- `P(quest_success|T,O) = P(Y < required_fails | T,O)`；七人以上第四任務需要兩張失敗票才失敗。
- 完整策略應最大化 `E[terminal_win | history, action, player_policy]`，而非直接最大化 `IG(T)`。

## 認識論上的三個區別

- **世界真相**：遊戲伺服器持有的真角色（只在對局結束／評估時可揭露）。
- **玩家真實可見資訊**：私人角色視角 + 已公開行動與任務結果。
- **玩家主觀信念**：在假定 q、語言可靠性等模型下的後驗；可能錯、且可能過度自信。

同一玩家可能對壞人熵下降，卻對梅林遭刺殺的風險評估上升。需要區分 `H(EvilSet)`、`H(MerlinSeat)`、`H(RoleAssignment)`。

## 偏差與混淆

| 風險 | 控制方式 |
|---|---|
| 知道真角色後倒推發言 | 每回合只能使用當時合法可觀測資訊，時間戳與資料遮罩測試 |
| 文章的策略描述是選擇性案例 | 原文命題逐項標註「經驗假說」，不能直接當統計定理 |
| 相關語言訊號重複計分 | 先依訊號來源/語義事件分群，必要時採條件依賴模型 |
| 各玩家 q 不同 | 進行 q 敏感度和分層貝葉斯校準，不用一個數字宣稱實戰概率 |
| 成功/失敗與失敗張數混淆 | 明確記錄實際可公開欄位：fail_cards、success_flag、threshold |
| 多次嘗試挑最好策略 | 預先註冊主要指標，訓練/驗證/測試按遊戲與玩家群分割 |
| 單一自我對弈風格過擬合 | 跨對手族群、跨配置、跨種子、跨版本做穩健性檢驗 |

## 實作階段與驗收

**M0（本次交付）**：規則子集 + 聯合信念 + entropy/IG + q 敏感度 + 單元測試。驗收：5 人 120 worlds、10 人 151,200 worlds、五人 q=1 任務兩人 `P(success)=0.3`，`IG_fail_count=1.295461844... bits`、7+ 人第四局兩張失敗例外、角色視角權限與證據一致性檢查。

**M1（未開始）**：完整房規設定（角色集合、規則與台灣慣例可切換）、可回放提案／贊否票／湖中／任務與刺殺；序列化 Event Schema；角色視角洩漏測試。

**M2（未開始）**：正式收集 AvalonLogs / Avalon-NLU / Bayesian-Avalon / AVCORP；依授權與資料清理檢查匯入。實作保留原始、正規化、衍生三層及可追溯來源 hash；對逐輪推理做 Brier score、log loss、ECE、AUC；進行真實對局基準比較。

**M3（未開始）**：計算雙方資訊量、提案與發言的策略效用。與 heuristic、random、CSP、GRAIL/DeepRole（若能公平重現）做事先固定配置的對照；報告勝率信賴區間與多次比較控制。

**M4（未開始）**：與可互動的阿瓦隆線上遊戲引擎整合，在伺服器實施私有資訊隔離；預設不要公開「AI 知道真角色」的任何全域資訊。
