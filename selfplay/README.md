# 平行自我對打（GitHub Actions）

推到分支 `selfplay-runs-r53`（第 53 回合自己的佇列）就會跑 `.github/workflows/selfplay.yml`：
- `selfplay/jobs.txt` 每行一段：`標籤|開關（空白分隔 k=v）|種子|起始局號|局數`。藍方座位 = 預設 + 開關，紅方 = 預設。
- `selfplay/config.json`：`runId`（結果目錄）、`shards`（同時開幾台，最多約 18）、`parallel`（每台同時幾段，runner 4 核）。
- 每一段的結果（只有每局的勝負、三藍、刺中梅林、第 1 局失敗、失敗任務數和對局雜湊，沒有對局紀錄）推到分支 `selfplay-results` 的 `results/<runId>/`。
- 已經有結果的段落會跳過，重跑同一個 runId 只補缺的。
- 和本機跑同一段逐局相同（同一套種子：`種子|局號`）。
- 實驗 E-loyal（只在這個分支）：`--flag eloyal=A|B` 讓梅林、派西、紅方（含奧伯倫）的提議與投票都交給「同一座位、只看公開資訊的預設忠臣」
  （看不到紅方、拇指；自己拿湖看到的結果保留）；任務牌、湖、刺殺照預設。A = 紅方連第 5 次強制提議也照忠臣；B = 紅方當第 5 次強制提議的隊長時照預設紅方；C = 同 A，但派西照預設（用拇指）。
- 第 53 回合（只在這個分支）：`--flag pickAudit=1` 在忠臣視角的好人隊長挑隊時記下機器人的隊和精確挑隊（`Round53.cleanScores53`：後驗、L1* 均勻）的比較，加一欄 `pa`（行為不變）。
