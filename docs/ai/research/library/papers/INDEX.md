## 使用說明

1. 書目核對和閱讀狀態在 [READING_MATRIX.md](./READING_MATRIX.md)，由 Claude/ChatGPT 逐篇留下可驗證證據；不以猜測標註 `full_text_read`。
2. 精華與落地工作在 [核心論文筆記](./NOTES.md)，每一條須能追溯到論文或過往有標註的閱讀紀錄。
3. 對照現有研究 [r7_literature.md](../../r7_literature.md)、[infl_research.md](../../../infl_research.md) 和獨立 Python PR #15。避免重複計數。
4. 不要把五人局 CFR、狼人殺結果外推為本平台十人含湖、強制第五提案的收益。
