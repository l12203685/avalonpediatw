## 0. Edward 的裁定（2026-11-04）

1. **強者參考**不用原始角色勝率（會挑到角色專家、整體打得弱的人）：
   - 母體 = 網站 Elo 前 20%（`analysis_cache.json` → `rating.players`；非暫定、≥ 50 場的人裡取前 20%）。目前 **10 人**。
   - 高強度局 = 桌上平均開打前 Elo（`games_cache.json` 的 lineup 第 4 欄 = 每個座位 Elo×10）在所有局的前 30%。目前 **≥ 1501.3，1659 局裡 498 局**。
   - 分面分開評估，絕不混成一個勝率：(a) 任務階段（藍方贏在三藍死或三藍活、紅方贏在三紅；反映派隊／投票／湖／任務），在高強度局量「超過該角色平均」的超額、分陣營；(b) 刺客刺中率 = 當刺客時 三藍死 /（三藍死＋三藍活）；(c) 梅林存活率 = 當梅林時 三藍活 /（三藍死＋三藍活）。
   - 每種決策對到它的分面：藍方角色的派隊／投票／湖 → 藍方任務王；紅方角色的派隊／投票／湖／任務牌 → 紅方任務王；刺殺 → 刺客刺中王（樣本太小改用全部局）；梅林風格 → 梅林存活王。
   - 小樣本向那個人的陣營超額收縮。
2. **不再有讀人用的「機器人表」**：一套讀人模型擬合強者，機器人往它收斂；「機器人行為 − 強者模型」是每回合要縮小的診斷（第 5 節）。
3. **D3 分階段解除**：忠臣先學會在有把握時，用公開資訊投異常票（內黑／外白），例如很確定尾家（第 5 次強制局隊長）是紅；之後梅林／派西只在「同樣公開資訊的忠臣也會」的範圍內投異常票。沒有「注定否決的提議」：每一個提議都要當成可能出任務。

## 2. LOOP 行（`strongLoopMetrics.ts`）

`scripts/strongLoopMetrics.ts`：資料 = `games_cache.json` 用 `datasetReplay` 嚴格解析（2314 局 → 可重播 2223 局，其中高強度 468 局），名字從資料集的座位欄補上（只在記憶體裡）。決策點與 `agreement.replayGame` 相同：只給那個座位當時知道的東西，看現行預設（`DEFAULT_AGENT_TUNING`、正式路徑）做不做一樣的決定。

- **群組**：每一種決策比對它自己的分面（第 0 節）：忠臣、派西的派隊／投票／湖 → 藍方任務王；梅林 → 梅林存活王；紅方的派隊／投票／湖／任務牌 → 紅方任務王；刺殺 → 刺客刺中王。前 5、前 3 兩組，各分「全部局」與「高強度局」兩欄；另外每局抽 1 個座位（局 id 雜湊）＝「全體真人的決策點」對照欄（`抽樣`）。

## 3. 異常票：真人 vs 機器人

同一支 `strongLoopMetrics.ts` 印的第二部分（`abnormalVotes.ts`、`strongData.votesOf`）。

**定義**：
- 內黑 = 在隊上投反對（隊長算在隊上）；外白 = 不在隊上投贊成。強制局（第 5 次）沒有投票、不算；只算票數和結果相符的提議（`votesReliable`）。
- 率：異常票率 = 異常票 / 全部票；內黑率 = 內黑 / 隊上的票；外白率 = 外白 / 隊外的票。
- **藍方準度**：外白「對」= 那隊沒有紅；內黑「對」= 那隊有紅。要和基準比：隊上有紅率（內黑全猜「有紅」的命中）、隊外乾淨率（外白全猜「乾淨」的命中）。
- **紅方**（沒有對錯）：外白分「推隊友」（隊上有紅）／「貼藍」（全藍的隊）；內黑分「隊上有隊友」／「落單」；**之後有沒有被讀成紅** = 下一局起，藍方隊長派的隊選他的比例，和同一次提議投正常票的紅方比；**關鍵票** = 改投就翻轉結果。
- 來源：真人強者（投票分面前 5 的座位）、機器人@強者點（同一批決策點換成現行預設的票，重播）、真人抽樣／機器人@抽樣點（每局抽 1 個座位＝全體真人的決策點）、真人全體（每一張可信的票）、自我對打（現行預設 500 局）。

各角色 R3+ 異常票率（真人強者 / 機器人@強者點 / 自我對打）：忠臣 19.8 / 34.8 / 26.3%、派西 21.2 / 36.9 / 25.9%、梅林 24.7 / 35.2 / 30.4%、刺客 26.5 / **4.6** / 7.0%、莫甘娜 24.4 / **6.3** / 6.3%、莫德雷德 27.1 / 17.0 / 14.5%、奧伯倫 24.2 / **47.1** / 34.1%。

回合 × 次數（藍方異常票率，真人強者 → 機器人@強者點）：第 1、2 局每一格真人 2–8%、機器人 1–3%（D3：自我對打 0%）；R3A1 16 → 32%、R3A2 14 → 32%、R3A3 18 → 34%、R3A4 18 → 25%（第 4 次真人外白 23%、機器人 3%）；R4A1 25 → 45%、R4A4 26 → 38%（真人外白 25%、機器人 1%）；R5A1 37 → 43%。紅方：R4A1 真人強者 41%（外白 48%）、機器人 15%；R5 真人強者 42–48%、機器人 21–34%。完整表（每格附內黑率／外白率與藍方準度）見腳本輸出。

讀法：
- **「真人投更多異常票、準度更高」要分開看**：第 1、2 局真人確實投得多（藍方 5.2% 對 1.6%）；第 3 局起藍方機器人反而**多很多**（35.2% 對 20.8%），全部多在**內黑**（55.9% 對 25.1%），外白只有真人的三分之一（5.1% 對 14.5%）。真人的內黑準度較高（80.4% 對 73.9%，基準 65.8%）：機器人在隊上反對了很多其實乾淨的隊。
- 機器人外白的準度看起來高（40.5%、R3+ 61.3%），但量只有真人的三分之一、集中在最明顯的情況；真人的外白在尾家很紅時明顯上升（第 4 節），機器人沒有。
- 紅方：強者紅方第 3 局起異常票 25.6%，機器人 17.5%；**刺客、莫甘娜幾乎不投異常票**（4.6%、6.3% 對 26.5%、24.4%），奧伯倫反過來太多（47.1% 對 24.2%）。紅方內黑真人多半是隊上有隊友（67.8%），機器人自我對打多半是落單（74.5%）。
- 紅方的異常票有代價：之後藍方隊長選他 15.5%，投正常票的紅方 20.8%（全體 13.1 / 18.3%）。

## 4. 尾家（強制局隊長）

`scripts/strongTailLeader.ts`。第 1–4 次提議時，第 5 次（強制局）的隊長 = 現任隊長往後 5 − 次數 個座位（`tailLeaderSeat`）。每一次提議、每一個藍方座位（真人局 2223 局、自我對打 500 局；`--views 10` = 全部藍方座位），用**現行預設的貝氏信念**（`bayesOptionsOf(DEFAULT_AGENT_TUNING)`）站在那個座位、當成沒有角色視野的忠臣（只有他自己湖到的結果）＝「同樣公開資訊的忠臣」，算 P(尾家是紅)。約 2 分鐘。

**校準**（真人局，154,728 點）：

| P 格 | n | 平均 P | 真的是紅 |
|---|---|---|---|
| 0.0–0.1 | 23,203 | 2.2% | **19.1%** |
| 0.1–0.2 | 7,580 | 15.0% | 35.6% |
| 0.2–0.3 | 8,357 | 25.1% | 40.1% |
| 0.3–0.4 | 11,097 | 35.7% | 41.2% |
| 0.4–0.5 | 46,749 | 45.2% | 45.1% |
| 0.5–0.6 | 15,951 | 54.5% | 48.7% |
| 0.6–0.7 | 10,458 | 64.8% | 50.7% |
| 0.7–0.8 | 8,121 | 74.8% | 54.6% |
| 0.8–0.9 | 7,306 | 85.0% | 57.9% |
| 0.9–1.0 | 15,906 | 97.2% | **72.1%** |

Brier 0.248，**和只猜紅方比例的常數（0.247）一樣**；log2 損失 1.16。高強度局相同（0.253）。自我對打 Brier 0.230（0.9–1.0 格 82.9%、0.0–0.1 格 18.6%）。

**藍方投票者**（依自己的 P 分段；外白率｜外白準度 / 隊外乾淨基準｜內黑率）：

| P(尾家紅) | 真人強者 | 真人全體 | 機器人自我對打 |
|---|---|---|---|
| < 0.3 | 8.3%｜37.1 / 14.6%｜17.5% | 7.6%｜42.4 / 14.6%｜18.1% | 5.4%｜78.7 / 17.0%｜35.3% |
| 0.3–0.7 | 6.7%｜24.0 / 13.6%｜7.1% | 4.3%｜20.4 / 13.6%｜5.6% | **0.1%**｜—｜6.3% |
| **≥ 0.7** | **19.2%**｜36.7 / 15.5%｜20.8% | **18.1%**｜35.2 / 16.9%｜19.1% | **10.8%**｜56.3 / 17.1%｜32.6% |
| ≥ 0.7，第 4 次提議 | **31.3%** | **31.2%** | **4.8%** |
| ≥ 0.7，尾家真的是紅 | 24.2% | 21.8% | 13.1% |
| ≥ 0.7，尾家其實是藍 | 10.8% | 11.9% | 5.8% |

**收場**（每回合第一次「提議層 P ≥ 0.7」的提議之後；提議層 P = 所有藍方座位的平均）：

| | n | 任務成功 | 藍方終局贏（三藍活） | 尾家真的是紅 | 出任務的隊有紅 |
|---|---|---|---|---|---|
| 真人：前面的隊過了 | 1,790 | **59.8%** | 33.0% | 68.2% | 56.1% |
| 真人：拖到強制局 | 770 | **29.4%** | 27.4% | 44.4% | 78.1% |
| 自我對打：前面的隊過了 | 305 | 64.3% | 37.0% | 76.7% | 45.2% |
| 自我對打：拖到強制局 | 272 | 26.5% | 32.0% | 54.0% | 80.1% |
| （對照）真人 P < 0.3：前面過了 / 強制局 | 1,247 / 1,781 | 74.2 / 38.0% | 43.0 / 27.4% | 16.8 / 25.3% | 45.1 / 72.0% |

讀法：
- **現行預設讀真人的尾家沒有鑑別力**（Brier = 常數），兩端過度自信：說 P < 0.1 的有 19% 其實是紅，說 P > 0.9 的只有 72%。高 P 格還是比低 P 格紅很多（72% 對 19%），所以「很有把握」仍是有用的訊號，但門檻要用校準過的值：P ≥ 0.7 實際約 55–72%。
- 真人在尾家看起來很紅時**外白多了一倍以上**（19% 對 4–7%），第 4 次提議（下一個就是強制局）到 31%；強者和全體差不多。機器人在中段幾乎不外白（0.1%），P ≥ 0.7 的第 4 次提議只有 4.8%——**D3 第一階段要學的就是這一格**。
- 外白準度：真人在 P ≥ 0.7 時 36.7%（基準 15.5%），機器人 56.3%：機器人外白得少但準；真人用量換到的是「不讓尾家強制」。
- 收場：尾家很紅時，前面的隊過了任務成功 59.8%、拖到強制局 29.4%（藍方終局 33.0% 對 27.4%）。**這是觀察性的比較**：拖到強制局的回合本來就是大家意見分歧、紅方在搗亂的回合；尾家看起來很藍（P < 0.3）時拖到強制局也一樣差（38.0% 對 74.2%）。能說的是「強制局的隊有紅 78%」：尾家很紅時讓前面的隊過，至少不比強制局差。

## 6. 限制

- 母體只有 10 人；分面前 5 是其中一半。刺中率、存活率的樣本小，前 3／前 5 對門檻（15 次、K = 10）敏感。
- 決策點在同一局內相關；表中的差距沒有做局的集群區間。
- 真人資料只有紀錄、沒有發言；「強者實際」裡有一部分是發言帶來的資訊，模型讀不到。
- 機器人重播是「把機器人放進真人的局」：之前的紀錄是真人打出來的（機器人沒走到過的局面）。自我對打是機器人自己的局面分布。兩欄要一起看。
- 尾家的忠臣視角用現行預設的貝氏信念；它在真人局沒有鑑別力（第 4 節），P 分段應該當成「機器人會怎麼想」而不是真相。收場的比較是觀察性的（會拖到強制局的回合本來就不一樣）。
- 差距模型是邏輯迴歸：第 1、2 局機器人幾乎是決定性的，模型會把強者的小比例異常票抹平；所以同時列經驗版（強者實際 vs 機器人重播）。
- 自我對打只有 500 局（約 3 分鐘）。
- 本研究沒有改任何既有的 `src/ai` 檔案；正式預設的行為完全不變。
