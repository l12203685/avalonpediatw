# AI 與真人決策一致性基準（Agreement Benchmark）

**日期**：2026-10-12 · **資料**：`packages/server/sheets_cache.json` 的 `牌譜`（快照）
**主要對象**：ED（Edward）· 對照：Sin、各角色高勝率玩家群（top/role）、全體玩家（population）

重跑（決定性，同資料同碼結果完全相同，約 2.5 分鐘）：

```bash
pnpm --filter @avalon/server exec tsx scripts/agreementBenchmark.ts --player ED --player Sin [--limit N] [--json out.json] [--no-population]
```

## 1. 方法

- **資料**：2146 場有文字記錄 → **1970 場可逐步重播的 10 人局**（嚴格解析；176 場因記錄錯誤排除，最多的是 `X-` 標在非隊員 56、`X+` 標在隊員 43、失敗牌多於紅方人數 16）。ED 280 場、Sin 997 場。
- **重建觀測**：依正式伺服器 `GameServer.buildBotObservation` 的接線，替該座位在每個決策點重建 `PlayerObservation`（角色私訊：梅林見刺/娜/奧、紅方互見不含奧、派西見兩拇指；公開歷史：每次提議與完整票型、任務結果、已宣告的湖）。隊長 = 每場自座 1 起每次提議輪轉（含強制局，跨回合不重置）。第 5 次提議為強制局（不投票，記為全贊成）。
- **Agent**：每座位一個常駐 `HeuristicAgent`，呼叫 `act()`（正式路徑；USE_FORWARD_REASONING=true → 283,061 個決策經 ForwardAgent，0 次 fallback）；湖用新的 `pickLakeTarget` / `declareLake`。`Math.random` 依（局、座、決策）播種。
- **比較的決策**：派隊（完全相同 / Jaccard）、投票（排除強制局與票數和結果不符的提議）、任務牌（僅紅方且失敗數能確定其牌）、湖目標、紅方湖宣告（以真人實際湖的對象為條件）、刺殺目標。
- **基準**：
  - *default*：投票 = 正常票（隊內白、隊外黑）；派隊 = 重提本回合上一隊（或上一任務隊）並換入自己；紅方任務牌一律失敗；湖宣告 = 說實話；湖目標 / 刺殺 = 隨機（1/候選數）。
  - *rule*：少量公開資訊規則（R3 起避開失敗任務成員與已知紅；紅方有隊友就贊成；R4 單紅不足兩失敗時出成功；湖失敗任務最多者；紅方湖宣告反說；刺殺最常反對含紅隊伍者）。
- **勝負**：標準規則 — 三紅與三藍死 = 紅勝，三藍活 = 藍勝（具名 10 人局紅勝約 70%、藍勝約 30%）。

## 6. 解讀

**一致的地方**：R1–R2 投票（agent 94–100%，略高於「正常票」基準，因為 R1–R2 鎖正常票）；好人湖宣告（幾乎 100%）；R2/R3 刺客、莫甘娜、莫德單紅上任務的出牌（≥93%，奧伯倫除外）。

**分歧最大的地方**：

1. **R3+ 投票**（量最大：population 9.2 萬筆）：agent 61% 低於「正常票」基準 80%（Sin 87%、ED 76%）。agent 異常票率 37%，真人約 20%（ED 24%、Sin 13%）。主要是紅方隊外為含隊友的隊投白、以及藍方隊內遇到失敗任務成員就投黑。
2. **派隊**：完全相同僅 3–4%，Jaccard 約 40%，**比「重提上一隊」基準（Jaccard 約 49%、完全相同 10–13%）還低**。R3+ 真人比 agent 更常把失敗任務成員放進隊（他們已經縮小紅方範圍）；R2 則反過來是 agent 放入 R1 失敗成員。
3. **湖目標**：真人（含 ED：好人 R2 湖 19 次中 14 次湖失敗任務成員）多半湖**有失敗紀錄的人**；agent 好人刻意湖**最低嫌疑**的人（2026-04-29 修正 #2「首湖藍」）。ED 一致率僅 2%。
4. **紅方湖宣告**：ED 當紅方 14 次有 13 次說實話（default 92.9%）；agent 對好人目標常宣「紅」，與 ED 只 50% 一致。
5. **刺殺**：agent 只比亂猜好一點（population 刺中梅林 17.9%，真人 44.5%；top 刺客 51.8%）。
6. **任務牌**：ED 69% 低於 population 77%；ED 與 top 的差異集中在 R1/R4 的「該不該藏」（R1 莫甘娜單紅出失敗、R4 單紅出成功、R1 雙紅一起出成功）。

**agent 有比較像 ED 嗎？** 沒有明顯的。ED 與 population 的一致率在多數項目差不到 1–2 個百分點；ED 在異常票上稍高（45% vs 40%），但任務牌（69% vs 77%）和湖目標（2% vs 12%）反而更低。

## 7. 可調參數（附快速消融實驗）

消融：在 ED / Sin / top 群上暫時改程式重跑（未提交），只動單一項。

| 槓桿 | 位置 | 改動 | ED | Sin | top |

| R3+ 正常票先驗 | `ForwardAgent.decide` team_vote 評分 | 正常票加 +0.3 | 投票 R3+ 61.6→66.1、異常率 36.9→25.9% | 62.3→71.0 | 59.0→64.7 |
| | | +0.6 | 68.2、異常率 21.4%（≈ED 24.3%） | 74.5 | 67.6 |
| | | +1.0 | 72.0、異常率 14.5% | 78.7 | 71.5 |

| 紅方湖宣告 | `LakePolicy.decideLakeClaimForTeam` 紅方分支 | 一律宣「好」 | 50.0→85.7% | 61.1→87.0% | 60.4→77.6% |
| 紅方任務牌 | ForwardAgent quest_vote / `RoleStrategy` | R4 可見紅 <2 出成功；R1 莫甘娜單紅出失敗 | 69.3（不變） | 79.8→85.3 | 79.7→82.7 |

建議優先序：

1. **R3+ 投票加「正常票先驗」**（ForwardAgent 目前在評分時完全沒有異常票的曝光成本）。量最大、效果最大；+0.6 時 agent 異常率約 21%，與 ED（24%）、top（21%）相近，R3+ 一致率提升 6–12 個百分點。具體分支：紅方隊外為含隊友隊伍投白（`computePurposeAlignment` threeRedWins +1 與 `RoleStrategy` 的 approve 偏好 +0.5/+0.6）、藍方隊內見失敗成員投黑（threeBlueWins / findGoodTeam 以 avgSuspicion 決定）。注意：只是更像真人，勝率影響要另跑自我對弈驗證。
2. **紅方湖宣告**：ED 幾乎都說實話，top 也偏向宣「好」→ 把 `merlinScore ≤ 0 → 宣紅` 的預設改成宣好（或說實話），+17–36 個百分點。
3. **好人湖目標**：「首湖藍」修正與 ED 的實際打法相反；改湖失敗任務成員可讓 ED 一致率 2%→14%，但 top 群略降（11.7%）→ 建議做成依情境（例如 R2 有失敗任務時湖失敗成員）而非全面翻轉。
4. **刺殺**：agent 刺中率明顯落後真人（18% vs 45–52%），值得用 top 刺客的牌譜當監督訊號檢查 `HeuristicAgent.assassinate` 的特徵權重。
5. **派隊**：在 `generateTeamSelectCandidates` / `PRIOR_PENALTY`（懲罰重提被否決的隊）上，真人很常沿用前一隊；R3+ 對失敗任務成員的排除可放寬為「已被縮小範圍的成員才排除」。
6. **任務牌**：R4 單紅出成功、R1 莫甘娜單紅出失敗，Sin/top 各升 3–6 點；ED 樣本小（101）、不受影響。

## 8. 限制

- 舊記錄常漏記通過隊的異常票：票數與結果不符的提議不計投票分數（約 3% 非強制提議）。
- 任務牌只計「失敗數能確定其牌」的情況，偏向全成功或全失敗的局面。
- 正式環境的觀測不保留湖主私下看到的結果，重播也不給（與線上一致），會影響湖後的派隊與投票。
- 僅 10 人局；R1 依本地慣例幾乎都是 5 次提議，R1 派隊訊號低。
- 自我對弈 harness 的派西 `knownEvils` 為兩拇指，正式伺服器為空陣列（本基準依正式環境）。
