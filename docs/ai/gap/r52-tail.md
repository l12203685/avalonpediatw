# 第 52 回合：1-5／2-5 尾派——真人忠臣／派西 vs 機器人（完整表）

產生方式（沒有玩家名、沒有對局紀錄）：

```
cd packages/server
npx tsx scripts/tailPickStudy.ts --out rows.jsonl            # 真人局 games_cache.json 嚴格重播（不含 ProAvalon、百科AI 局），機器人 = main 預設
python3 -I scripts/tailPickStudy.py rows.jsonl --md out.md
```

決策點：第 1、2 局第 5 次提議（強制局），隊長是忠臣或派西。強者 = 隊長座位開打前 PR ≥ 80（第 51 回合 B 的定義）。
比例後面是 Wilson 95%；平均是 ±1.96 SE；`*` = 區間不含 0。忠臣 − 派西是獨立樣本的常態近似；機器人 − 人類是同一個決策點的逐點配對。
機器人 = 同一個座位、同一個角色、只看當時公開資訊（`agreement.replaySeat` 的持續 agent 與種子，重播到這個決策點）。
任務成功、三紅／三藍死／三藍活是人類那一隊實際的結果（機器人的隊沒有出任務，只有「全好隊」可比）。

特徵（都只用派隊當下的公開紀錄）：派自己；照派這一局前面的某一隊（整隊一樣）；第 1 局的隊全在（2-5：3+1）；隊長出過第 1 局任務；
和前面提議最多重疊；隊員（不含隊長）在這一局被選最多的 k 人裡（k = 隊員數）、被選 ≥ 2 次、沒被選過、平均次數；
隊員贊成率 − 隊外贊成率（這一局前面可信的票）；隊員投第 4 次贊成的人數；隊員投過外白／內黑（整局前面可信的票）；
隊員裡第 1 局出任務的人；機器人隊長自己的後驗（`bayesTeamClean`，同 `goodCleanLead`）說這隊沒有紅的機率；真相：隊上紅數、梅林／莫甘娜（派西的兩根拇指）在不在隊上。
