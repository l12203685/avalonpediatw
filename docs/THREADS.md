# Threads 每日一題草稿

用實戰牌譜出 Threads 每日一題，產生每天要貼的草稿。發文由站長自己來：沒有接 Threads API，也不會自動發。第一則留言由 ChatGPT 寫（Issue #37）。

## 貼文格式（站長 2026-11-11 定案）

每天發一篇新貼文 A，用「引用」的方式引用昨天的貼文 B。

- B 的內容是問題 1＋解答 0；A 的內容是問題 2＋解答 1。
- A 的第一則留言放跟這題有關的數據冷知識或觀念，加上文章網址。
- 不另外在昨天的貼文底下串答案，不用私訊對答案，也不當天公布。
- 第一篇是 **2026-11-17**（`THREADS_START_DATE`），題目是 36AKW-2-5。那一天的 A 只有題目，沒有昨天的答案。

## 怎麼跑

```bash
pnpm --filter @avalon/server threads:draft                        # 今天（台北日期）
pnpm --filter @avalon/server threads:draft -- --date 2026-11-18   # 指定日期
pnpm --filter @avalon/server threads:draft -- --week              # 從 --date（預設今天）起連續 7 天
# 其他選項：--days N、--out <資料夾>、--no-image、--start YYYY-MM-DD（第一篇的日期，預設 2026-11-17）
```

輸出放在 `packages/server/threads_drafts/`，這個資料夾不進 git。每天產生三個檔：

| 檔案 | 內容 |
|---|---|
| `<日期>.md` | 給站長複製貼上：① 新貼文 A（引用昨天的貼文發）、② A 的第一則留言 |
| `<日期>.json` | 同樣的內容，另外記下題目（`pick`）和放進 A 的昨天答案（`answerToYesterday`）。ChatGPT 把第一則留言寫進 `firstComment.text` |
| `<日期>.png` | 題目圖：座位、你的視角、任務進度、到目前的牌譜、輪到你做什麼 |

已經有 `<日期>.json` 的日子，會沿用檔案裡的題目和第一則留言，重跑不會換題。所以就算題庫或牌譜連結之後更新了，昨天貼出去的題目和今天 A 裡的答案還是對得上。

## 每週主題（2026-11-11）

| 星期 | 今天的題目 | A 裡的昨天答案 |
|---|---|---|
| 週一 | 刺殺梅林（你是刺客，三藍之後輪到你刺） | 週日那題的完整答案 |
| 週二 | 派西維爾思考（派西第 2 局起第一次當隊長） | 週一的梅林 |
| 週三 | 1-5 尾派（選第二局開紅、之後輪得到 3-5 的局） | 週二派西那題的完整答案 |
| 週四 | 同一局接到 3-5 | 週三真人派了什麼和純邏輯的理由（幾好幾壞和角色週五才公布；站長 2026-11-17「照現在這樣」） |
| 週五 | 2-5 尾派（優先選之後輪得到 4-5 的局） | 週三、週四兩題的完整答案 |
| 週六 | 同一局接到 4-5 | 週五真人派了什麼和理由（完整答案週日公布） |
| 週日 | 第五局決策 | 週五、週六兩題的完整答案 |

- **只出實戰：** 題庫 `sim_bank.json` 本來就不含模擬的局，網站牌譜的連結也跳過模擬的貼文。
- **視角：** 尾派題優先用忠臣、派西的視角，沒有才用梅林。
- **選局：**
  - 優先選網站上有牌譜頁的局。
  - 同一週不重複出同一局。
  - 一輪的局還沒出完之前，每週也不會重複。
- **沒有能連著的局時：**
  - 週六改出「第四局忠臣派 5 人」（Issue #37）。
  - 週四改出獨立的 3-5。

## 新貼文 A 的內容（≤ 500 字）

1. 標題（主題）。
2. 今天的題目：
   - 你的座位和角色。派西附拇指、梅林附看到的紅、刺客附隊友。
   - 到目前的牌譜。
   - 輪到你做什麼、怎麼留言作答。
3. 「── 昨天 題號 的答案 ──」：
   - 真人派了什麼、幾好幾壞、任務結果；
   - 一行純邏輯的理由；
   - 角色代碼和結果；
   - 網站牌譜連結。
4. 題號，以及最後一行的主題標籤 `#阿瓦隆`（站長 2026-11-17）。

**放不下 500 字時，先縮題目：**
1. 前面幾局只留任務結果和湖。
2. 還是放不下，就只寫「完整局面看圖」。
3. 最後才把答案裡的理由拿掉。

牌譜連結一定留。完整局面都在圖裡。

**理由**只用那一家當下看得到的資訊來算：
- 紅方還有幾種可能；
- 真人這隊在幾種裡全好；
- 全好機會最大的隊。

**② 第一則留言**由 ChatGPT 填。草稿附上：
- 建議的百科文章，用分享網址 `/w/<id>/`，Threads 會顯示預覽卡片；
- 這一題的關鍵字。

草稿和圖只有座位和牌譜記號，沒有玩家名字。第十個座位寫「0家」。

## 站長選局（2026-11-17）

站長 11/17：「我如果需要 看到未來一週 甚至一個月的文章安排 並且我可以自己選擇牌譜(從候選名單中挑 盡量是S高一點的優先)」，
以及「不能先用條列式表格呈現牌譜就好嗎 (像googlesheet 那樣) 我可以先用條件來篩出自己想要的」。

- **S 是什麼：** 網站的「陣容強度」（站長 10/31）：每局賽前十個座位在當時玩家池裡的 PR 平均，S ≥ 65 是網站的高強度局。
  來源是 `games_cache.json` 每局的 `lineup[1]`（S×10），用 `generate_cache.py record_fingerprint` 同一個指紋對上題庫的局（`src/bots/threads/strength.ts`）。
  題庫 1,778 局有 1,218 局對得上 S；對不上或不評分的局 S 顯示「—」，排在最後。牌譜整併（#38）之後 1,777 局有網站牌譜頁。
- **選局頁：** 站長私人的 claude.ai 頁面（不在公開網站上），兩個分頁：
  - **日曆：** 從第一篇（11/17）起 28 天，每天目前的題目和照 S 由高到低的前 15 個藍方視角候選（刺殺題是刺客），再補 5 個有網站牌譜頁、S 最高的。
  - **牌譜表：** 題庫每一局一列（像試算表），欄位：題號、S、網站牌譜、第 1–5 局任務（`oox`／`ooox`／`ooxx`…，沒打到的局空白）、結果（三紅／三藍死（刺中）／三藍活）、
    刺殺座位、1–0 家角色、派西維爾位置、派西資訊（兩根拇指＝梅林、莫甘娜）、梅林位置、湖（`0>5x`：0 家湖 5 家說壞）、可出題型（1-5、1-5→3-5、2-5、2-5→4-5、3-5、第4局忠臣5人、第5局、刺殺、派西）。
    每欄都能篩（任務、角色、座位、題型多選；題號、拇指、湖文字含；S 最低值），每一局「選給…」只列主題對得上、還沒鎖住的日子。
  - 頁面附帶 `candidates.json`、`games.json`（`threads:candidates` 產生）；站長選的寫進頁面資料庫的 `picks/<日期>`（`{ date, exerciseId, nextExerciseId, chosenAt, … }`），只有擁有者能寫。
  - 週三、週五選了能連著打的局，隔天自動接同一局；週四、週六另選就改出獨立的題目。已經貼出去的日子（`THREADS_POSTED`，11/17 36AKW-2-5）和今天以前的日子鎖住。
- **選擇的正本：** commit 進 repo 的 `packages/server/threads_picks.json`（自動發佈 #48 的格式）：`{ "version": 1, "picks": { "YYYY-MM-DD": "<題號>" } }`。
  產生器只有一條選題的路：`pickOverride`（存下來＝已經發出去的那一天優先；選的題不是那天主題能出的就照計畫，原因寫進 `warnings`）。
  選局頁列出來的題號（`optionsFor`）跟 `pickOverride` 用同一套池子，一定接受。
- **腳本：** `threads:candidates`（`--picks` 預設 `threads_picks.json`；輸出 `candidates.json`、`games.json`，不進 git）、`threads:draft -- --picks <檔>`（只用今天之後的日子）。
  `--picks` 也接受選局頁資料庫匯出的 `[{ "date": …, "exerciseId": … }]`。

### 每天早上 8 點（台北）的工作

1. 讀選局頁資料庫的 `picks` 集合（ArtifactData `list`，collection `picks`），只留今天之後的日子，
   同步進 `packages/server/threads_picks.json`（`picksFileBody`，日期排好）；有變動就 commit（選擇的正本在 repo）。
2. 產生今天的草稿（或由自動發佈 #48 讀 `threads_picks.json` 發文）。
3. 重跑 `threads:candidates -- --today <今天>`，把新的 `candidates.json`、`games.json` 更新到選局頁（今天鎖住、後面的日子照選擇重排）。
