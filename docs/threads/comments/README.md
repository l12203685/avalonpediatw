# Threads 第一則留言

每天一個檔：`YYYY-MM-DD.md`（台北日期），整個檔案的內容就是那天貼文 A 底下的第一則留言「阿瓦隆百科小觀念」。
現在由 Claude 寫（站長 11/18 起；原本是 ChatGPT，Issue #37），寫好開 PR 給站長審。

格式：

```
【阿瓦隆百科小觀念】
2–4 句白話，扣著那天的主題或局面。
https://avalon-game-platform.web.app/w/<文章 id>/
```

- 純文字，含標題和網址 ≤ 300 字（Threads 上限 500）。
- 內容出自那天草稿建議的百科文章（`<日期>.json` 的 `firstComment.articles`）：寫到的事實要在文章裡找得到，數字只引用文章已有的。
- 不劇透當天的答案、不寫那一局的角色；比分這類只寫出題當下的公開資訊；座位寫「N家」「0家」，不寫玩家名字。
- `<!-- -->` 註解會被拿掉，可以拿來寫備註。
- 那天沒有檔案時，自動發佈會用備案：「今天這題跟「關鍵字」有關，觀念整理在這篇：」＋建議文章的網址。
- 建議的文章和關鍵字：跑 `pnpm --filter @avalon/server threads:draft -- --date YYYY-MM-DD`，看產生的 `<日期>.json` 裡的 `firstComment`。
