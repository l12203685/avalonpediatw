# 藍方基礎原則

## 大原則

- 【邏輯】盡可能選擇你視角中的好人。
- 【經驗】不要搞事，當個正常人。

## 亞瑟的忠臣

- 【邏輯】任務派票，就是選你視角中的「好人」。
- 沒有被選進任務時，不要「**隨便**」外白（注意，重點是「隨便」）。【經驗】
  - 沒被選進任務組合時，不該輕易外白。
  - 【邏輯】隨便同意一個沒有自己的組合出任務＝讓壞人更容易進任務。
- 被選進任務時，不要「**亂開**」內黑（注意，重點是「亂開」）。【經驗】
  - 被選進任務組合時，不該輕易內黑。
  - 【邏輯】反對有自己的組合出任務＝減少好人進任務的機會。
- 更深入請見[為什麼不該亂開異常票（外白與內黑）](wiki:wiki-38)、[異常票基礎 - 內黑與外白的意義](wiki:wiki-44)。

## 派西維爾

- 【經驗】不要盲目相信你的雙拇指。
  - 在有足夠資訊（`派票`）之前，不要直接選（`採`）你的雙拇指（梅林、莫甘娜）。
  - 這是對梅林的基本尊重；沒有足夠的資訊與理由就去選，等於擲硬幣賭博。
  - 賭贏只是運氣好，沒人會開心。
  - 賭錯肯定當戰犯，吃力不討好。
- 更深入：[角色玩法 - 派西維爾](wiki:wiki-176)、[派西為什麼不要盲採拇指](wiki:wiki-111)

## 梅林

- 原則上不派你看得到的紅方（拇指）。【經驗】
  - 【本站立場】可以順應局勢與資訊派拇指，但不是為了躲刺而派；詳見[梅林可以派拇指嗎 - 順應局勢，不是為了躲刺](wiki:wiki-213)。
  - 【時效】原文：「現階段或許很容易死；等到藍方好人越來越會玩，梅林會越來越輕鬆。」（依賴社群當下的讀票程度）
- 更深入：[角色玩法 - 梅林](wiki:wiki-175)
