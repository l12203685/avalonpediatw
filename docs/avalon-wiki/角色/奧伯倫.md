# 角色玩法 - 奧伯倫

> 「對邪惡方來說彼此互不了解」

## 角色能力

### 奧伯倫是邪惡陣營的能力者

- 【規則】遊戲開始進入夜晚，主持人請所有人閉眼。
  - 壞人相認階段，奧伯倫不睜眼，不知道隊友是誰，隊友也不知道他。
  - 梅林確認壞人的階段，奧伯倫要豎起大拇指。
- 【規則】只有梅林知道奧伯倫的明確位置。

### 奧伯倫的重要任務

- 【規則】盡力破壞任務，不要怕與隊友同時出任務失敗。
- 【經驗】確認紅方隊友的位置，並協助隊友破壞任務。
  - 開出關鍵的第 6 顆贊成白球（10 人局需要 6 顆白球才過半）。
  - 適時無限開白，讓隊友直接利用你的白球。
- 協助刺客辨認梅林。
  - 【規則】全場只有梅林 100% 知道奧伯倫的明確位置。
  - 【經驗】若有玩家在關鍵時刻突然反對你進任務，極有可能是梅林。
  - 【規則】在刺殺階段表達自己的視角，找出梅林可能人選。
- 【經驗】隨機應變。
  - 有時第一局出完失敗後，就無限開白，等同「登出」（不再爭取進任務）。
  - 有時混進忠臣好人堆中直到第五局，再逼迫梅林出來阻止。
  - 奧伯倫終究是邪惡方，不要讓遊戲變成 7 打 3（10 人局：6 好 4 壞，奧伯倫若站到好人那邊就成了 7 打 3）。

## 角色定位

- 【經驗】增加遊戲的變化性。
  - 拉低紅方下限。
  - 提高紅方上限。
  - 很容易有個人風格。
- 【邏輯】奧伯倫的大局觀＝玩雜魚時的思考能力。
  - 奧伯倫玩得好不好，取決於玩雜魚的技術好不好。
  - 平常雜魚怎麼找好人跟壞人，奧伯倫也一樣。
- 【經驗】反過來盤就好：
  - 對你沒敵意的能力者，大概率是隊友。
  - 對你有敵意的能力者，大概率是好人能力者。

## 基本策略

### 任務為主

- 【經驗】被選進任務就先出失敗。
- 【經驗】初學者先不用考慮是否有隊友。
  - 不用怕被罵，就算出現兩張失敗也不應該被罵。
  - 第一局出現兩張失敗（oxx）比任務成功（ooo）更有助於紅方拿下三紅。（原文稱「統計數據顯示」，未附來源；比較對象也宜改為「一張失敗」，見）
  - 第二局若有湖中女神，出現兩張失敗還可以降低湖中女神的可信度。
- 這只是大方向，並非定律。

### 控場為輔

- 【邏輯】一般來說，奧伯倫能比其他忠臣更快找到其他紅方（他知道自己是壞人，也知道場上還有其他壞人）。
  - 依照場上風向做出對紅方陣營有利的選擇。
  - 如果判斷任務中有紅方隊友，可以嘗試出任務成功，讓隊友出失敗。
- 要分得出每種結果的效益並進行選擇：
  - 一張失敗：賺。
  - 兩張失敗：打平（你還是拿下了一局任務）。
  - 開藍：大虧。
- 相對地，如果判斷錯誤，也要有隨機應變的做法。

### 要不要喊炸車？

- 【經驗】沒必要就不需要做這件事。
- 喊炸車等於放棄每一次練習的機會。
- 同樣，這只是大方向，並非定律。

## 奧伯倫要點

### 前期

- 【經驗】如同所有能力者，盡量以雜魚視角思考。
- 【經驗】裝雜魚派票，不讓人發現你是能力者。

### 後期

- 後期指的是身分已經暴露（例如 1-5 開出 oxx、到 2-4 全場都不派你、遊戲兩紅壞人聽牌等）。
- 【經驗】找機會幫隊友衝白球。
- 【經驗】或是開擾亂用的白球（你知道開這顆白球不會讓任務出去，但會讓大家難以判斷其他人的陣營）。

### 尋找紅方隊友

- 疊隊友的票。
- 帶相認壞人進任務。
- 咬掉不是隊友的好人。

### 尋找好人能力者

- 從好人能力者的視角找到你的隊友。
- 觀察是否有人對你或某些人釋放敵意。

### 欺騙藍方忠臣

- 【規則】因為不相認，不會發生隊友派票閃你的情況。
- 【經驗】盡可能讓其他人來派你，藉此縮減梅林人選。
- 【經驗】不要讓其他人發現你是能力者，越像雜魚越好。
- 特別注意：
  - 欺騙的目的是在最後關鍵時刻反咬一口。
  - 該表壞的時候就果斷表壞，不要扭捏。
  - 裝好人裝到 5-5，梅林會感謝你，刺客會想捅爆你。

### 誤導場上資訊

- 製造錯誤區間。
- 沒票的好人，就盡量讓他一直沒票（越多好人被當成壞人，你就相對變成好人，比較能出任務）。

### 擔任尾派時

- 判斷自己的身分有沒有暴露，再決定行動：
  - 是否要派你認為的隊友。
  - 是否要派場上公認偏好的人。
  - 是否要表壞（擾亂資訊，並幫助隊友拿下後續任務）。
- 派隊友的情況
  - 目標：拿到一張任務失敗，並增加任務外好人派出全好組合的難度。
    - 通常會選任務內的一個人。
    - 【邏輯】因為你帶了隊友，就算你不被選，隊友被選到的機會也大幅增加。
  - 若要帶隊友，就不要再帶下一局的尾派。
    - 以 1-5 而言，就是帶 0 家＋隊友出任務。
    - 【經驗】通常這時 0 家不會派隊伍內的人。
    - 自然就有兩個紅方被排除在外。
  - 奧伯倫出失敗還是相認紅方出失敗，比的是戰術與默契，分成以下幾種情況：
    - 【經驗】一般情況通常是奧伯倫藏，讓相認紅方出失敗。
    - 奧伯倫派得很突兀、明顯就是來出失敗的：相認紅方自己要躲好。
    - 奧伯倫找到隊友，相認紅方自己出。
    - 奧伯倫找到隊友，相認紅方也找到奧伯倫，結果兩人都不出。
  - 【邏輯】不要派一個很好的好人 A 跟一個很壞的隊友 B。
    - 這樣大家很自然會選 A，等於兩個壞人都被丟在外面。
- 帶兩個好人的情況
  - 目標：拿下任務失敗，並拖兩個好人下水。
    - 用雜魚視角派票，讓大家無法區分第一局的壞人是誰。
    - 【經驗】最好是帶一個偏好、一個模糊的好人，讓兩人一起被懷疑。
  - 若場上有兩個偏好的人：
    - 可以全都帶上（記得，如果你是雜魚，自然會帶偏好的玩家）。
    - 迫使 0 家在 2-5 只能選其中一個偏好的人。
    - 或是先讓任務成功，迫使 0 家加進來，再出失敗。
- 找好人能力者
  - 帶上好人能力者出任務並出失敗，但不能做得太明顯。
  - 如果好人能力者對自己沒有敵意，直接派他，然後出失敗。
  - 從可能的梅林視角確認隊友位置，隨機應變。

## 結論

- 擴大隊友的優勢。
- 尾派時思考如何在破壞任務的同時混淆場上資訊：
  - 讓 0 家再派一次有紅方的組合。
  - 讓後面的好人派錯。
  - 縮小其他梅林人選。
  - 掩護隊友。
- 如果沒有把握，就出失敗搶三紅。
- 表壞有好的表壞做法，最差的做法是用嘴巴認壞。
- 每個人玩法不一樣，但請記住你終究是紅方，不要演好人演過頭。
