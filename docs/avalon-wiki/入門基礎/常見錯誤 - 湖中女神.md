# 常見錯誤 - 湖中女神

> 本篇各節列出的都是常見錯誤，除另有標示外屬於【經驗】。
>
> 【本站立場】有目的、不是無腦的湖法都有討論空間；一個湖中動作有沒有效益，要事後覆盤才知道，湖中選擇很難一概而論。下面列的是「沒有理由」時的錯誤。

## 使用錯誤

- 鐵壞拿到湖中，把湖女還給鐵好。
- 鐵好拿到湖中，沒有理由就湖另一個鐵好（怕場上讀不懂時湖鐵好是保守的選擇，見[湖中女神使用方針](wiki:wiki-147)）。
- 鐵好拿到湖中，湖另一個鐵壞。

## 忘記湖中線的優先序

- A 湖 B 說好，B 湖 C 說好 ⇒ 身分高低鏈 C > B > A（見[鐵邏輯、正邏輯與反邏輯](wiki:wiki-66)）。【邏輯】
- 此時認為 A、B 是好人，卻不認為 C 是好人。【邏輯】

## 藍方使用湖中女神後說謊

- 遊戲規則中並沒有說「好人不能說謊」。【規則】
- 但說謊對該玩家所屬的陣營沒有幫助（藍方為了遊戲目標不會說謊）。【邏輯】
- 自己是藍方玩家時，不該在使用湖中女神後說謊。【經驗】
- 同理，若認為湖中女神的使用者是藍方，就不該懷疑他宣告的結果。【邏輯】

## 思考不周全

- 任務結果出來之後，才想湖中該怎麼用。

## 好人常見錯誤

- 只為了自己使用湖中，沒有擴大場上最需要的共同資訊。
- 沒有根據局勢使用湖中：
  - 紅方聽牌
  - 藍方聽牌
  - 一藍一紅
  - 一紅一藍

> 各局勢怎麼湖，見[湖中進階](wiki:wiki-208)。

## 壞人常見錯誤

- 沒有適時封鎖資訊：
  - 有時候表壞湖是必要的
  - 不需要一直幫好人擴展資訊
- 該說謊時沒說謊：
  - 壞湖壞說壞：等於直接讓兩個壞人被放在任務外，同時不用進任務
  - 沒有理由就壞湖好說好：導致你必須幫場上好人認下那個好人（有目的的表好是另一回事，利弊見[湖中女神使用方針](wiki:wiki-147)）
