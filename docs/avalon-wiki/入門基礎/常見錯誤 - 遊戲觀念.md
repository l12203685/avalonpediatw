# 常見錯誤 - 遊戲觀念
## 不知道自己在做什麼
* 新手第一課: 知道自己在做什麼
* 要知道自己每個動作代表的意義
* 知道自己想表達什麼, 並透過動作表達
## 為了爽而不是為了遊戲目標(獲勝)
* 147, 258 => 接著派369
* 固定"**無腦**"派一些組合 (147, 150, 678, 123, 234, 789, ...
* 喜歡"**無腦**"買尾家票 (xy5, xyz0, ...)
## 忘記遊戲目標演戲演過頭
* 壞人努力當好人
    * 不敢出任務失敗
    * 不封鎖資訊
    * 關鍵時刻不衝隊友進任務
* 好人努力當壞人
    * 梅林一直送壞人進任務, 三紅遊戲結束後梅林說: 抓不到我吧~哈哈!
    * 派西維爾當成自己沒看到梅林/莫甘娜, 都派進任務試試看
    * 忠臣演壞人, 目的是為了"騙"壞人送自己進任務
## 花時間研究/覆盤資訊不足的牌譜
* 123 234 345 (150 250 350) ...
* 147 258 369 (148 259 360) ...
* 169 278 345 (167 289 350) ...
* 梅林莫甘娜連續互派, 派西維爾同時把梅林莫甘娜派進任務還開藍
* 這幾種牌譜通常不是因為贏的那方玩的好, 而是運氣或是對手玩太爛
## 把特例當常態
* 永遠在想鬼故事
    * 整天覺得壞湖壞說壞
    * 認為壞人使用複雜的戰術
* 整天被害妄想症
    * 開藍都覺得裡面有藏
    * 第二局開紅都不相信湖中結果
    * 認我好人的都先當壞人
