# 為什麼不建議跳派西

## 跳派的出處

- 一般玩阿瓦隆的場合常習慣「跳派」，這來自玩狼人殺時跳預言家的習慣。【慣例】
- 但跳派反而會降低藍方勝率，並且破壞遊戲體驗。【經驗】
- 派西維爾壓力已經很大，還跳派成為焦點，容易被找到資訊來源（也就是梅林）。【經驗】
- 派西維爾一定有最基本的內建資訊：梅林和莫甘娜這兩個人一好一壞。【規則】
- 只要知道誰是派西維爾，就能從派西維爾的視角找出誰是他的內建資訊來源。【邏輯】

## 降低藍方勝率的理由

- 說跳派會降低藍方勝率，常會有以下疑問：
  - 兩紅了，我不該跳出來率領大家求勝嗎？
  - 如果紅方跳派西，難道梅林和派西也要坐視不理嗎？
  - 先三藍才有機會啊！說不定紅方會刺錯！
- 跳派能「三藍」，是建立在以下前提：【經驗】
  - 藍方妥協，無條件服從你
  - 紅方不花時間對跳，也不和你比拚狀態發言
- **但三藍不等於贏。**【規則】
  - 跳派達成三藍的同時，也暴露了視野【經驗】
  - 容易被紅方找出梅林（確實也有少數情況是跳派後，梅林依然沒被刺客找到）【經驗】

## 全場玩家的遊戲體驗

- 場景一：
  - 你剛坐下開始玩阿瓦隆，抽到了紅方
  - A 玩家直接對大家說：「我只有拿到派西才會跳派西，所以請相信我」
  - 請問紅方要放棄這場遊戲嗎？
- 場景二：
  - 這次你是藍方
  - 輪到你派票，正準備頭腦風暴、思考找好人出任務
  - B 玩家跳出來：「我是全場唯一真派，若不帶我，你就是鐵壞」
  - 你聽信他，派了 B 玩家和 C 玩家，卻不幸任務失敗
  - 派西繼續要求下一任隊長，而你又繼續發呆
  - 其餘藍方也只能放棄思考，無條件聽這個人領導嗎？

## 玩一場能獨立思考的阿瓦隆

- 每個人都能自主思考：「你有理由跳派，我也有理由不信你」。【慣例】
- 派西維爾不能死皮賴臉地只會說：
  - 「不管，我是派西，就是要在車上」
  - 「聽我指揮，不聽我的通通當壞人」
  - **這是不尊重其他玩家的遊戲體驗**【慣例】
- 能獨立思考的理想遊戲環境應該是：以派票為主、發言為輔、不靠狀態；聊天和玩笑可以有，玩遊戲還是要開心。【本站立場】
- 盡量避免跳派，讓大家有獨立思考的空間。【慣例】
- 就算某些情況下不跳派會輸掉遊戲，也請不要剝奪其他人思考的樂趣。【慣例】
