# 遊戲基本規則與流程

> 作者：Ed

## 遊戲說明

- 阿瓦隆是一種陣營遊戲，分成藍方（好人陣營）與紅方（壞人陣營）。【規則】
- 藍方具有人數優勢；紅方具有資訊優勢。【邏輯】
- 兩個陣營各有需要達成的目標。不論何時，都請清楚知道自己所屬陣營的遊戲目標。【經驗】

## 遊戲目標

### 藍方陣營：完成以下「所有」條件

- 任務結果成功三局（簡稱「三藍」）。【規則】
- 避免梅林被刺客刺殺（簡稱「躲刺」「躲刀」）。【規則】

### 紅方陣營：完成以下「其中一個」條件

- 任務結果失敗三局（簡稱「三紅」）。【規則】
- 引導刺客正確指認梅林並刺殺成功。【規則】

> 規則書的寫法是「同一局五次否決，紅方獲勝」【規則】；本站採尾家強制局（每局第 5 次提議不投票、直接出任務），因此不會因否決次數分出勝負【慣例】。為什麼可以不投這一次，見[規則說明書](wiki:wiki-203) 6.3 與[名詞：任務指派](wiki:wiki-150)的「尾派」。

## 藍方的遊戲目的

### 拿下三次任務成功

- 拿下任務成功的關鍵：找出好人；避免壞人出任務。【邏輯】
- 拿下三次任務成功的關鍵：透過資訊的交換找到足夠的好人。【邏輯】

### 避免梅林被刺客指認（也稱為擋刀）

- 雜魚多嘗試不同組合，以分散風險。【經驗】
- 找到梅林，並鞏固梅林的資訊。【經驗】
- 資訊給得比梅林快，而且正確。【經驗】

## 紅方的遊戲目的

### 幫助刺客成功指認梅林

- 使忠臣與派西維爾犯錯：【經驗】
  - 排除不是梅林的對象（簡稱「排水」）
  - 誤導好人在任務選擇時選到紅方隊友

## 角色說明

> 邪惡能看清自己，梅林卻關照未來。

### 正義方

- **梅林**：知道誰是邪惡方，但必須隱藏好自己的身分。【規則】
  - 梅林看得到除了莫德雷德以外的所有邪惡方。【規則】
  - 如果讓刺客發現你是梅林，只要被正確指認，依然算邪惡方勝利。【規則】
- **亞瑟的忠臣**【規則】
- **派西維爾**：知道誰是梅林。【規則】
  - 知道梅林的位置。
  - 莫甘娜會以梅林的形象出現。
  - 夜晚階段，派西維爾會看到兩根拇指。
  - 但無法區分莫甘娜和梅林分別是誰。

### 邪惡方

- **刺客**：莫德雷德的爪牙。【規則】
  - 找到梅林，並在任務三藍後正確指認。
- **莫德雷德的爪牙**：普通的壞人。【規則】
- **莫甘娜**：以梅林的形象出現。【規則】
  - 夜晚時，派西維爾會看到你與真梅林的位置。
  - 但派西維爾無法區分莫甘娜和梅林分別是誰。
- **莫德雷德**：梅林不知道他。【規則】
  - 唯一不會被梅林看到的壞人。
- **奧伯倫**：對邪惡方來說彼此互不了解。【規則】
  - 夜晚邪惡方相認時不能睜眼。
  - 不會知道其他邪惡方的位置。

## 遊戲流程

1. **抽取角色卡，並決定起始玩家（「1 家」）**【規則】
   ![角色卡](https://i.imgur.com/bwz2yAz.png)
   ![角色卡](https://i.imgur.com/gGVIOMC.jpg)
   - 若有配置湖中女神（簡稱「湖女」「湖中」），將它交給起始玩家的上一位玩家（「0 家」）。
   - 湖女的使用時間點：第二、三、四局任務的〔任務階段〕結束後。
2. **夜晚陣營確認**【規則】
   - 奧伯倫以外的紅方豎起拇指，睜眼互相確認拇指位置。
   - 莫德雷德以外的紅方豎起拇指，梅林睜眼確認拇指位置。
   - 梅林與莫甘娜豎起拇指，派西維爾睜眼確認兩根拇指的位置。
3. **由起始玩家開始，順時針進行以下流程**【規則】

### 〔隊伍組合選擇階段〕

1. 隊長將任務指示牌（盾牌）分派給任務組合的人選。【規則】
2. 隊長宣告確定任務組合後，進入〔投票階段〕。【規則】
3. 例外：當局的第 5 次提議（n-5）由當局第 5 位隊長（尾家）派隊，不投票，直接進入〔任務階段〕（尾家強制局）。【慣例】

### 〔投票階段〕

1. 玩家對任務組合選擇贊成（白球）或反對（黑球），反面覆蓋。【規則】
2. 所有玩家確定自己的選擇後同時翻開，依下列情況處理：【規則】
   - 若贊成票總數未超過遊戲玩家的一半：
     1. 順時針傳遞隊長標記。
     2. 由下一位玩家擔任隊長，回到〔隊伍組合選擇階段〕。
     3. 若下一位隊長是當局第 5 位隊長（尾家），他的提議不投票，直接出任務（本社群慣例：尾家強制局）。
   - 若贊成票總數超過遊戲玩家的一半，進行〔任務階段〕。

### 〔任務階段〕

1. 任務組合內的玩家各領取一張「任務成功」和一張「任務失敗」卡。【規則】
   ![任務成功與任務失敗](https://i.imgur.com/1MjKR2b.png)
2. 任務組合內的玩家選擇要出的任務卡，覆蓋後打出，不能讓任何其他玩家知道。【規則】
3. 藍方玩家只能選擇「任務成功」；紅方玩家可以選擇「任務失敗」或「任務成功」。【規則】
4. 將所有玩家打出的任務卡洗勻後一起打開，結算任務結果：【規則】
   - 計算「任務失敗」的總數。
   - 若「任務失敗」為 0 張（全部都是「任務成功」），該局由藍方拿下（簡稱「開藍」）。
   - 只要出現一張以上「任務失敗」，該局由紅方拿下（簡稱「開紅」）。
   - 遊戲人數 7 人以上的第四局（也稱作「保護局」）：
     - 「任務失敗」必須有 2 張以上才會開紅，否則都是開藍。【規則】
       ![](https://i.imgur.com/YGnDRpM.png)
       ![](https://i.imgur.com/2astsQm.png)
     - 稱為保護局的原因：
       - 保護藍方，使第四局幾乎都能開藍。【經驗】
       - 第四局開藍，代表第四局的任務組合最多一壞，或是兩個不相認的壞人（照正常打法，兩位相認紅方同進第四局會一起出失敗）。【經驗】
       - 配合第四局的任務組合與最後一次湖中女神，在決勝局前可以獲得極大量的資訊。【經驗】
5. 標示任務結果（藍或紅）後，判斷要進入哪個階段：【規則】
   - 判斷雙方陣營的第一目標是否達成（「三藍」或「三紅」）：
     - 若「三紅」達成，紅方獲勝。
     - 若「三藍」達成，進入〔刺殺階段〕。
     - 若都未達成，判斷是否進入〔湖中階段〕。
   - 〔湖中階段〕結束後、不需要進入〔湖中階段〕或未配置湖女時：
     - 傳遞隊長標記，開始下一局。
     - 進入〔隊伍組合選擇階段〕。

### 〔湖中階段〕

1. 湖上夫人（湖女）的使用時間點：第二、三、四局任務的〔任務階段〕結束後。【規則】
2. 持有湖女的玩家，將陣營卡與湖女交給被湖的玩家。【規則】
3. 被湖的玩家**必須將自己的真實陣營卡回傳**給使用湖女的玩家。【規則】
4. 用湖的玩家**可以選擇**是否宣告結果（好／壞、藍／紅、正義／邪惡、龍／鳳），**也可以選擇說謊**。【規則】
5. 湖中階段結束。

### 〔刺殺階段〕

1. 根據規則書說明，此時只有刺客可以將底牌翻開。【規則】
2. 只有邪惡方（紅方）可以討論刺殺對象；正義方（藍方）在刺殺階段不可發言。【規則】
3. 紅方可以透過發言得知彼此角色，因此等同所有邪惡方（包含奧伯倫）一起翻牌討論。【邏輯】
4. 最終選擇權仍在刺客手中：指認對象是梅林，該局紅方獲勝；反之藍方獲勝。【規則】

> 有些地方的 Home Rule 是「奧伯倫不可參與刺殺討論」。這類 Home Rule 是為了增減紅藍雙方的相對強度或遊戲變化性，沒有絕對的好壞，只要大家有共識即可。【慣例】

## 各階段簡略流程

- 〔隊伍組合選擇階段〕→〔投票階段〕【規則】
  - 白球未過半 → 移交隊長 → 新一輪〔隊伍組合選擇階段〕（第 5 次提議由尾家派隊，不投票，直接進入〔任務階段〕；本社群慣例）
  - 白球過半 →〔任務階段〕→ 任務結果 → 判斷是否達成遊戲目標（三藍／三紅）
    - 都未達成 →〔湖中階段〕→ 新一輪〔隊伍組合選擇階段〕
    - 三紅 → 紅方獲勝
    - 三藍 →〔刺殺階段〕
      - 刺客指認梅林正確，刺殺成功 → 紅方獲勝
      - 刺客指認梅林錯誤，刺殺失敗 → 藍方獲勝
