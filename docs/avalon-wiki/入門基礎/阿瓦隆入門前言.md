# 入門前言 - 用派票說話，發言為輔

## 前言

感謝你的閱讀。會看到這裡，代表你對阿瓦隆有了興趣，也好奇別人是怎麼玩這個遊戲的。

## 遊戲認知

- 先來討論對這個遊戲的認知與特徵：【經驗】
  - 玩這個遊戲時，是不是很容易有人吵架，氣氛到最後都很糟？
  - 大家七嘴八舌拼命說話，場面混亂？
  - 如果是線上玩阿瓦隆，連當下是誰在說話都分不清楚？
  - 每場遊戲時間都超過一小時？
- 如果有上面幾點，代表遊戲習慣還停留在**「用嘴巴說話給資訊」**的階段。【經驗】

## 依賴發言釋放資訊的特徵

- 耗費時間：【經驗】
  - 因為每個人都習慣發言
  - 一次派票就要所有人（10 人局即十個人）紛紛表示一次意見
- 場上過度混亂：【邏輯】
  - 每個人隨時隨地都可以透過講話傳遞資訊
  - 在不受限制的情況下，甚至可以說一個人能釋放無限多的資訊
  - 無限多、又不一定正確的資訊會導致資訊混亂
- 聲音有情緒與狀態起伏的問題：【經驗】
  - 為了讓其他人相信自己的發言內容，只好開始透過狀態、爆水等舉動
  - 表明自己是某角色來博取信任（最常見的是「我是派西維爾！」）

## 如何避免上述情況

- 一場遊戲的過程：【經驗】
  - 不該被大量的爆水發言、狀態以及吵架話語穿插
  - 而是盡可能透過遊戲機制挖掘蛛絲馬跡
- 以下是本百科在多場遊戲後整理的心得：
  - 讀者可能不認同其中部分內容，本百科會持續修正改進
  - 讀者也可能認同其中部分內容
  - 歡迎一起用這些角度思考、摸索遊戲的樂趣
  - 也歡迎說明不認同的原因與理由

## 回歸遊戲的目標、元素與規則

- 阿瓦隆的目標：【規則】
  - 藍方陣營目標：三局任務成功，**且**梅林不被刺客指認
  - 紅方陣營目標：三局任務失敗，**或**梅林被刺客指認
- 阿瓦隆的元素：【規則】
  - 任務指派（「派票」）
  - 黑白球／同意反對（「投票」）
  - 任務結果（「藍／紅」）
  - 湖中女神
- 阿瓦隆的規則：
  - 所有資訊都必須是公開資訊；私下用通訊軟體互通角色是大忌。【慣例】
  - 其他規則詳見[阿瓦隆規則說明書（10 人局）](wiki:wiki-203)或阿瓦隆遊戲說明書。【規則】

## 結合目標、元素與規則的化學效應

- 藍方為了達到遊戲目標：【邏輯】
  - 「基本上」會盡可能在任務指派時，選擇他們認為也是藍方的人
- 紅方為了達到遊戲目標：【邏輯】
  - 「基本上」會盡可能在任務指派時擾亂資訊，讓藍方選到紅方
  - 使任務失敗，或是排除這些人是梅林的可能性
- 白球代表你「贊成」當下隊長給出的組合。【規則】
- 黑球代表你「反對」當下隊長給出的組合。【規則】
- 結合以上幾點：【邏輯】
  - 每位玩家所選的任務組合（派票）
  - 以及對任務組合投出的黑白球（投票）
  - 都非常有意義（含有大量資訊）

## 最常見、玩家人數最多的陣營遊戲類比：狼人殺

- 阿瓦隆的「派票」，重要性如同狼人殺的「絕對發言」。【經驗】
- 阿瓦隆的「投票」，重要性如同狼人殺的「回應」。【經驗】
- 一場阿瓦隆，每位玩家的派票機會很少：最多 2.5 次（10 人局 5 局都打到第 5 次提議，25 ÷ 10），實際平均約 1.5 次（見文末時效資料）。【邏輯】
- 每次有人給出派票組合，所有玩家都會投票回應。【規則】
- 下一位隊長又能馬上針對這些回應進行派票。【規則】
- 這個過程等同每個人都**持續**以「絕對發言」和「回應」對場上做出反應。【邏輯】
- 「派票」與「絕對發言」的不同點在於：【邏輯】
  - **每次派票都有可能真的出任務**
  - 真實性與意義性更高，更能代表一個人的立場與視角
  - 話語可以騙人，行為很難（因為要回歸遊戲目的）
- 用語建議：阿瓦隆中習慣稱紅方為「壞人／紅方／爪牙（常見於陸版）」，而不是「狼人／狼」。【慣例】
- 其他比較見下方〈阿瓦隆與狼人殺等陣營遊戲的比較〉一節。

## 小結：建議降低對發言的依賴

- 並非完全不說話，而是把重心放在遊戲元素、機制、規則衍生出的資訊：【經驗】
  - 任務結果
  - 湖中女神
  - 任務派票選擇
  - 黑白球投票
- 試著透過派票與投票展示自己的資訊與視角。【經驗】
- 研究如何從黑白球與任務中解讀出有用的資訊。【經驗】

| 資訊傳達比較 | 發言 | 派票 |
|---|---|---|
| 上手度 | 容易 | 困難 |
| 狀態加成 | 有 | **無** |
| 遊戲流程 | 混亂 | 流暢 |
| 遊戲時間 | 相對長 | 相對短 |
| 資訊內涵 | 直觀 | 複雜 |

（表格：【經驗】）

## 給帶新手的人

- 新手程度怎麼分、為什麼先講規則和遊戲目的、10 分鐘的教學順序，見[帶新手開局 - 10 分鐘教學腳本](wiki:wiki-217)。
- 什麼時候該說話、說什麼，見下方〈什麼時候該說話、說什麼〉一節。
- 【經驗】純派票很硬核：容錯率非常低，你的每一個選擇、每一次派票，甚至每一次黑白球，都是很重要的資訊。

## 常見 Q&A

### 不跳派玩什麼？

- 講話辯論當然是享受這個遊戲的一種方式，沒有對錯。【慣例】
- 不過講話時的情緒與語氣，有時會影響遊戲和其他玩家的視角。【經驗】
- 如同在狼人殺中，大家會偏好用邏輯盤狼坑的玩家，而不是天天靠爆水、爆狼找陣營身分的玩家。【經驗】
- 在阿瓦隆中，大多數資訊其實都可以用派票傳遞，因此沒有必要一直依賴嘴巴給資訊，或是「跳派求回應」。【經驗】
- 讓遊戲更純粹，透過邏輯與獨立思考來玩，這是本百科推廣這套玩法的原因。【慣例】

### 阿瓦隆就是要嘴砲才有趣啊！

- 不是不說話，跟朋友講垃圾話和幹話當然很愉快放鬆。【慣例】
- 這裡倡導的只是：避免太過求勝，不自覺地拉高狀態，變成吵架大會。【慣例】

### 只要有人不在特定邏輯架構內，就很容易整個垮掉；這是限制玩法、太死板

- 這裡分享的是「為自己的陣營取得最高效益、完成勝利目標」的操作。【經驗】
- 並沒有說「一定要這樣玩」，而是希望讓大家知道「原來阿瓦隆還可以這樣玩」。【慣例】
- 再次強調：**不是不說話，而是減少過度發言**。【慣例】
- 回歸思考每個人如何透過「行動」傳遞資訊，獲得不同的遊戲體驗。【經驗】

## 阿瓦隆與狼人殺等陣營遊戲的比較

### 本文對陣營遊戲的定義

- 將玩家分成兩個或多個陣營（排除一人一陣營的策略遊戲）。
- 大部分玩家不會知道其他人的真實身分（排除山中小屋、機密代號等）。
- 各陣營有獨立的獲勝條件。
- 以資訊交換、破解為主要玩法（排除 Bang!、三國殺、復仇女神號等）。

### 本文討論的對象

- 阿瓦隆
- 亞瑟傳奇
- 狼人殺
- 驚爆倫敦

### 陣營遊戲設計方式的異同

#### 資訊來源

- 資訊渠道的設立目的：讓玩家有機會摸清陣營，做出有利的決策。【邏輯】
- 場上共同知曉、且確定正確的資訊：【規則】
  - 阿瓦隆：任務結果
  - 亞瑟傳奇：任務結果
  - 狼人殺：強神、白狼王等角色的翻牌
  - 驚爆倫敦：剩下的炸彈數量
- 場上共同知曉、但不確定正確性的資訊：【規則】
  - 阿瓦隆：任務盾牌派票、黑白球投票
  - 亞瑟傳奇：任務盾牌派票、領袖交接順序
  - 其他玩家報出的資訊
- 僅個人知道、且保證正確的資訊：【規則】
  - 阿瓦隆：湖中結果
  - 亞瑟傳奇：護身符結果
  - 狼人殺：神職自己獲得的資訊（預言家、獵魔人、機械狼、惡靈板子的女巫等）
  - 驚爆倫敦：無
- 其他資訊渠道：
  - 個人行為、表情等
  - 個人言論
  - 場外

#### 資訊交流

- 發言（分為共同發言制與絕對發言制）
- 投票
- 其他方式

#### 資訊可信度

- 阿瓦隆的資訊可信度排序：任務結果 > 湖中女神 > 任務派票 + 黑白球投票 > 狀態發言（說明見[入門行動方針](wiki:wiki-106)）。【邏輯】
- 對照一般陣營遊戲的說法：一定真實的資訊（任務結果）優先，其次是比對後可信度較高的資訊（湖中），再來是仰賴解釋、分析的資訊（派票、黑白球），發言、抿牌、場外排最後。

### 阿瓦隆和狼人殺的比較（狼人殺以台式玩法為主）

| | 阿瓦隆 | 狼人殺 |
|---|---|---|
| 玩家數量 | 5～10 人【規則】；本站以 10 人局為主 | 6～12 人，常見 9～12 人 |
| 遊戲節奏 | 相對較快【經驗】 | 相對較慢 |
| 玩家參與度 | 相對較高（不會有人出局）【規則】 | 相對較低（首刀、首票） |
| 線上平台 | 不限 | 至少要有語音 |
| 給資訊的管道 | 任務派票、黑白球投票 | 絕對發言、狀態表情 |
| 給資訊的機會（派票） | 每人最多 2.5 次，本站牌譜實測平均約 1.5 次 | 平均 2～3 次 |
| 回應資訊的管道 | 後置位派票、**黑白球** | 後置位絕對發言、**投票票型** |
| 絕對可信的資訊 | 任務結果【規則】 | 翻牌 |

### 狼人殺玩家嘗試阿瓦隆

- 阿瓦隆的任務派票和狼人殺的發言一樣珍貴。【經驗】
  - 阿瓦隆不能亂派票，相當於狼人殺不能亂發言。
- 阿瓦隆的黑白球投票很重要。【經驗】
  - 相當於狼人殺中的票型。
  - 是表達站邊最直接的方式。
- 阿瓦隆中發言好但派錯票的人是壞人。【經驗】
  - 相當於狼人殺中瘋狂表水、但大上匪票的玩家。
  - 就算是好人，也會先被放在任務外，相當於狼人殺會優先票做匪事的玩家。

## 什麼時候該說話、說什麼 - 派票為主、發言為輔

### 重點
* 【建議】**派票為主、發言為輔、不靠狀態**
* 不是不說話，是 **減少過度發言**（本文〈入門前言〉）
* 有用的話只有一種：**公開資訊推得出來、而且和你的派票一致的話**
* 沒用的話：跳身分、貼臉、爆水、要別人讀心、喊炸車

---

### 根本：為什麼派票比發言可信
* 資訊可信度與思考優先序（[入門行動方針](wiki:wiki-106)）
    * **任務結果** > **湖中女神** > **任務派票＋黑白球** > **狀態發言**
* 【邏輯】派票可能真的出任務 => 派錯有代價 => 派票比較能代表一個人的立場
* 【邏輯】發言沒有代價 => 誰都能說、說什麼都行 => 可信度最低
* 【規則】遊戲中可以說謊，也可以宣稱自己是任何角色（[阿瓦隆規則說明書](wiki:wiki-203)）
    * => 一句話本身證明不了任何事
* 【經驗】話說越多，資訊越亂
    * 一個人可以透過說話釋放無限多的資訊；無限多又不一定正確的資訊 => 場上混亂（本文）
    * 線上局常常分不清是誰在說話
* 「人可以用演的、用說的、用騙的，但任務結果不會騙你」（[阿瓦隆心法語錄](wiki:wiki-72)）

### 什麼時候該說話
#### 1. 宣告湖中結果
* 【經驗】藍方會照實宣告湖中結果（wiki-106）
* 【經驗】藍方拿了湖不宣告，會被當成紅方訊號（[湖中女神 - 名詞、規則與使用方針](wiki:wiki-147)）
* 宣告要簡單：「0 湖 6，好。」

#### 2. 整理公開資訊
* 把大家都看得到、但可能沒注意到的事實講出來
    * 「158 `oxx`，158 至少兩壞，所以其他 7 人最多兩壞。」【邏輯】
    * 「6 被 0 湖說好，6 的身分比 0 好。」
* 【經驗】這種話對雜魚最有幫助，而且不會暴露你是不是能力者：誰都推得出來

#### 3. 說明你的派票（短）
* 一句話說你延伸誰、修正誰（[解讀前人派票 - 延伸、修正、尊重、分類與有意識的派票](wiki:wiki-24)）
    * 「我延伸 2 家的組合，換掉 7。」
* 【經驗】只說「推得出來的理由」；說不出公開理由的派票，不要用嘴補一個理由
    * 嘴巴補的理由和派票對不上 => 前後矛盾（[五個思考原理](wiki:wiki-26) 的一致性）
* 【經驗】不說也可以：派票本身就是發言（「派票就是說話；你可以不說話，但不能不派票」，wiki-72）

#### 4. 回答別人的問題
* 有人問你為什麼這樣派、為什麼內黑 => 用公開資訊回答
* 回答不出來 => 承認自己判斷錯了，比硬凹好（[能力者與超前資訊 - 誰有內建資訊、怎麼分辨好壞能力者](wiki:wiki-50)〈自我修正與前後矛盾的差別〉）

#### 5. 程序上的話
* 【慣例】兩紅後紅方確定必勝，可以提前宣告結束；有保護局時要確定必勝才喊（wiki-72）
* 【規則】刺殺階段：紅方可以公開討論；藍方不能說話

#### 6. 幹話
* 【經驗】玩遊戲要開心：跟朋友講垃圾話、幹話當然可以（本文）
* 只要不拿來當成推理的根據、不拉高狀態變成吵架

### 什麼不該說
* **跳身分**
    * 「我是派西」「我是梅林」：宣稱的身分不保證是真的，嚴格來說會提高紅方勝率（[角色玩法 - 派西維爾](wiki:wiki-176)〈為什麼不建議跳派西〉、[動作用語](wiki:wiki-204)）
* **貼臉、情緒勒索**
    * 「我只接受我跟 ABC 的組合，其他我都不同意。」
    * 「你不照我說的做，就是你雷。」（[常見錯誤 - 派票、黑白球、湖中、觀念與品格](wiki:wiki-90)〈遊戲品格〉）
* **爆水**
    * 講只有好人才會講的話，讓大家默認你是好人 => 把遊戲變成比狀態
* **用嘴巴喊炸車**
    * 【經驗】真的要表壞，用行動表達；就算開口，也只需要宣告出失敗，不需要跳身分
    * 「只會喊炸車的壞人，只是一條沒夢想的鹹魚」（wiki-72）
* **「我雜魚什麼都不知道」**
* **要別人讀心**
    * 「我派兩根拇指，是為了讓你們找到我是派西時，不會刺另一根拇指！」（wiki-90「認為別人有讀心術」）
    * 【經驗】三層已經是極限，大多數人停在第一層（[換位思考與思考的層次 - 代入別人的位置，三層是極限](wiki:wiki-27)〈思考的層次 - 三層是極限〉）

### 依角色
#### 梅林
* 【經驗】梅林說的話 = 梅林的派票：說太多 => 資訊來源就是你
* 【經驗】要說，只說公開資訊推得出來的話；讓自己的發言和雜魚一樣
* 【經驗】不要用嘴指出拇指；用派票，而且是雜魚也派得出來的派票（[角色玩法 - 梅林](wiki:wiki-175)〈梅林如何讓內建資訊和雜魚視角同步〉）

#### 派西維爾
* 【經驗】不跳派；不要出賣資訊來源（梅林）（[派西維爾](wiki:wiki-176)）
* 【經驗】梅林不咬的人你要咬：可以用公開資訊說出你對某人的懷疑，替梅林分擔

#### 忠臣
* 【經驗】忠臣最適合說話：你說什麼都只能來自公開資訊 => 整理公開資訊是忠臣的強項
* 【經驗】說明自己的修正：「我前面認 7 好，任務結果出來後改了。」

#### 紅方
* 【規則】可以說謊
* 【經驗】但你說的每句話都會被拿來和你的派票、黑白球對照；對不上就是破綻
* 【經驗】還沒被發現是壞人時，不要自己跟全世界說（wiki-72）
* 【經驗】假的推理最好也「公開資訊推得出來」，只是推到錯的地方（[鐵邏輯、正邏輯與反邏輯](wiki:wiki-66) 的反邏輯）

### 怎麼聽別人說話
* 【經驗】發言只當線索，最後都要回到派票和任務結果驗證
* 【經驗】對照他的話和他的派票
    * 說 A 好卻不派 A => 話和行動矛盾（[常見錯誤 - 派票、黑白球、湖中、觀念與品格](wiki:wiki-90)「想法矛盾或人選遺漏」）
* 【經驗】不要用狀態、人設、資料庫判斷
    * 「湖中猶豫了才說結果，怎麼可能是好人！」=> 不能這樣推（wiki-90「過度重視資料庫/人設/狀態」）
* 【經驗】講得很大聲、很肯定 ≠ 比較可信

### 線上和實體
* 【經驗】兩者大體相同，差在節奏和看得到的資訊
    * 實體節奏比較快；線上比較容易聽不清誰在說話
* 【經驗】不論線上或實體，用派票說話都比較不受影響

### 常見問題
* 「阿瓦隆就是要嘴砲才有趣啊！」
    * 不是不說話；是避免太過求勝、不自覺拉高狀態變成吵架大會（本文）
* 「不跳派，好人怎麼贏？」
    * 大多數資訊都可以用派票傳遞；跳派能三藍，也容易讓紅方找到梅林（wiki-176）
* 「都不說話，新手看得懂嗎？」
    * 【經驗】所以忠臣整理公開資訊的話特別有用；新手先學看懂派票，再學看懂發言

### 結論
* 【建議】派票為主、發言為輔、不靠狀態
* 該說：湖中宣告、整理公開資訊、一句話說明派票、回答問題、程序上的話、幹話
* 不該說：跳身分、貼臉、爆水、喊炸車、要別人讀心
* 判斷一句話有沒有用：**公開資訊推不推得出來？和他的派票一不一致？**
