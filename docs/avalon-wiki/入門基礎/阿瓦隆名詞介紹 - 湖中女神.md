# 名詞 - 湖中女神（湖上夫人）

湖中女神是亞瑟王傳說中的人物，傳說亞瑟王手中的王者之劍，就是由湖中女神所賜。湖中女神又被稱為湖夫人、湖中仙子、湖的貴夫人、湖中妖女。

阿瓦隆的遊戲規則書中，有一張「湖上夫人」的擴充卡，但大部分玩家通常稱這張卡為湖中女神，或簡稱湖中、湖女。【慣例】

- 規則書：**7 人以上**可以選擇將湖中女神加入遊戲。【規則】
- 本社群實測：**7 人以上**、而且有**莫德雷德**時才加入湖中女神，紅藍雙方的實力會比較平衡。【慣例】

## 湖中女神擴充卡介紹

- 湖中女神的功能：持有的玩家可以查看場上一名玩家的身分，並選擇性地說出該玩家的身分；被查看身分的玩家會成為下一位湖中持有者。【規則】
- 遊戲一開始，湖中放在最後一家（起始玩家的上家），這位玩家稱為「首湖」。【規則】【慣例】（「首湖」為社群稱呼）
- 湖中在第 2、3、4 局任務結束後使用；第 2 局後使用湖中的人（0 家）稱為「首湖」，第 3、4 局後使用湖中的人依序稱為「二湖」「三湖」。【規則】【慣例】

## 湖中女神的使用方法

- 第 2、3、4 局任務結束後，湖中持有者將「湖中女神卡」與「藍紅陣營卡」交給場上其中一位玩家（被湖者）。【規則】
- 被湖者必須將代表自己「真實身分」的陣營卡回傳給湖中持有者（簡單說：好人回傳藍卡，壞人回傳紅卡）。【規則】
  - 藍卡：金色徽章，中間有龍紋，代表正義方，也就是好人
  - 紅卡：銀色徽章，中間有鳳紋，代表邪惡方，也就是壞人
- 湖中持有者秘密查看陣營卡後，可以保持沉默、什麼都不說，也可以宣稱看到的結果。【規則】
  - 湖中持有者沒有被規定必須說實話，但湖中持有者一定會知道被湖者的真實身分（被湖者是壞人卻回傳藍卡，是違反遊戲規則的）。【規則】
  - 好人會希望場上的資訊都是正確的，因此湖中持有者若是好人，都會說實話，說出被湖者的陣營。【本站立場】
  - 所以「x 湖 y 說好」能推出的鐵邏輯是身分高低：y 的身分比 x 高（x 是好人時 y 必為好人），不是「y 一定是好人」（見[鐵邏輯、正邏輯與反邏輯](wiki:wiki-66)）。【邏輯】
  - 除了湖中持有者與被湖者，陣營卡不可以給其他人看，因此場上玩家必須自行判斷湖中持有者說話的真實性。【規則】
- 被湖者會成為下一位湖中持有者，而且曾經持有過湖中的玩家不能成為被湖者。【規則】

## 湖中女神相關名詞

- 好湖好：使用湖中與被湖的玩家都是好人。【慣例】
- 壞湖壞：使用湖中與被湖的玩家都是壞人。【慣例】
- 壞湖好：使用湖中的玩家是壞人，被湖的玩家是好人。【慣例】
- 壞湖問號／壞湖 X／壞湖 ?：使用湖中的玩家是壞人，被湖的玩家陣營未知。【慣例】
- 導湖：引導湖中去湖某位玩家。【慣例】

## 湖中女神使用範例

- 0 湖 8 說好（看到藍卡），8 湖 4 說壞（看到紅卡）。
- 0 代表起始湖，也就是首湖；8 代表二湖。
- 0 湖 8 說好：
  - 0 家對 8 家使用湖中
  - 8 家回傳真實陣營卡給 0 家
  - 0 家看完真實陣營卡後，宣稱自己看到的是好人
- 8 湖 4 說壞：
  - 8 家對 4 家使用湖中
  - 4 家回傳真實陣營卡給 8 家
  - 8 家看完真實陣營卡後，宣稱自己看到的是壞人
