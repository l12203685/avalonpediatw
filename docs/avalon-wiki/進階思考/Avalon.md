# 賽局思維 - 用混合策略平衡你的行動（6 家面對 1-5 開藍）

> 本文原為 PDF 轉檔（原檔名 Avalon.pdf，第 1 頁），以下依原文內容重新排版，論點不變。

## 賽局思維（Game Theory Thinking）

- 【邏輯】GTO（Game Theory Optimization，賽局最佳化）：讓電腦模擬各種狀況下、不同位置做不同動作時對勝率的影響，並用回溯（backtracking）的方式回調原本假定的各項機率。理論上每個情境（case）都能找到納許均衡（Nash equilibrium）。
- 【邏輯】實際上無法用電腦暴力算出阿瓦隆的納許均衡解，所以最好的方式是針對特定情境，設想自己在不同角色下採取各種行動的可能性，再簡化成可執行的策略（俗稱「工人智慧」）。

## 情境設定

- 情境：10 人局，1-5（5 家）派 570 開藍，你在 6 家。
- 身分簡化為三種：
  - r1：梅林
  - r2：壞人
  - r3：好人雜魚（含派西維爾）
- 行動簡化為三種：
  - a1：第一局 570 加自己（三加一）
  - a2：拆車
  - a3：外灑 570 加一位外置位
- 【邏輯】同一個角色所有行動的機率加總為 100%（下表任一橫列加總為 100%）：Σ P(r1, ai) = 100%。
- 【邏輯】6 家面對 570 開藍後，整體「三加一」的比率為（10 人局）：

```text
P(a1) = 0.1 × P(r1,a1) + 0.4 × P(r2,a1) + 0.5 × P(r3,a1)
        0.1 = 抽到梅林的機率
        0.4 = 抽到壞人的機率
        0.5 = 抽到好人（雜魚＋派西）的機率
```

### 行動機率矩陣（原文表格）

| 身分＼行動 | a1 三加一自己 | a2 拆車 | a3 外灑三加一 |
| --- | --- | --- | --- |
| r1 梅林 | P(r1,a1) | P(r1,a2) | P(r1,a3) |
| r2 壞人 | P(r2,a1) | P(r2,a2) | P(r2,a3) |
| r3 好人雜魚 | P(r3,a1) | P(r3,a2) | P(r3,a3) |

> 原文表格只有符號，沒有填入數值；下方各角色分析即為對這些數值的推估。

## 各角色的行動分析

### r1 梅林

- 【規則】梅林是好人能力者，知道 570 裡有沒有拇指。
- 【經驗】如果 570 全沒拇指，梅林高機率選 a1。
- 【邏輯】但這種針對 6 家的派票，加上 6 家自己是唯一的好人能力者，570 全沒拇指的機率理論上低於 50%，甚至更低。
- 如果 570 有壞人：由於第一局已開藍，梅林三種行動都可以選。
  - a1：放棄一次派票機會，等到自己下次派票時，高機率已是兩紅的第四局；好處是讓自己不會「只在 570 全好時才三加一」，達到平衡。
  - a2：直接給資訊，有被刺客盯上的風險，因此需要雜魚也同樣會拆車來平衡。
  - a3：各給一點資訊，是最不好的選擇——其他人不知道你討厭 570 裡的誰，也不知道你加的外置位是不是好人。
  - 例外：如果第一局是 578 之類開藍、0 家是拇指，就需要加入一定比例的 a3。

### r2 壞人

- 【經驗】570 這個派票很針對 6 家，所以奧伯倫也當作「有資訊的人」看待。
- 如果 570 有相認隊友：6 家壞人做三種行動都可以，這是最適合用來平衡整體行動線的狀況。
- 如果 570 沒有相認隊友：雙尾派都在任務內，壞人不做事的話高機率會三藍，所以高機率選 a2 或 a3；兩者比率應參考自己是梅林時的狀況，因此大致為：

```text
a2 > a3 >> a1
```

### r3 好人雜魚

- 【邏輯】在這種情境下，你有一半以上的機率是好人雜魚。如果你當雜魚時的行動和當 r1、r2 時有落差，就會出現漏洞（leak，馬腳），容易被抓出你是不是能力者。因此最好的方式是讓 r1、r2、r3 的行動整體均衡。
- 【經驗】身為 6 家好人卻被 570 這樣針對，前置位對你來說不太像有梅林，所以這時應該要有高頻率的拆車；而你身為 r1 和 r2 時也會有高機率拆車。
- 【經驗】雜魚至少也要有 50% 以上的比率選 a2 拆車，來保護 r1、r2 的身分。
- 【經驗】a3 對好人雜魚效益最低，比例應最低，只用來平衡 r2 壞人的行動線。行動比例大致為：

```text
a2 >> a1 > a3
```

## 簡化策略

- 【經驗】透過上面的分析，可以大致知道 6 家面對 570 開藍時各角色的選擇，最後要在實戰上簡化做法。
- 【經驗】理論上應加入少比例的外灑三加一（a3），但實戰上這條行動線只對 r2 壞人有明顯幫助，而且容易被其他玩家當作壞人；梅林做 a3 也常常讓派西吃不到資訊。
- 【經驗】一種實戰簡化是：省略 a3 這條行動線，在這個情境下不論什麼角色都有 80～90% 的拆車比例；剩下的 a1 由以下情況構成來平衡：
  - 梅林看到三好，順順加自己；
  - 梅林看到有拇指，但先不做事；
  - 好人雜魚躺分三加一。
