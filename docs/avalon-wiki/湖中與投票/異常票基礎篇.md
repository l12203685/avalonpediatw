# 異常票基礎 - 內黑與外白的意義

## 何謂異常票

- [名詞：黑白球投票](wiki:wiki-148)中提到兩種異常票：【規則】
  - 內黑：**隊伍內**的玩家**投反對**
  - 外白：**隊伍外**的玩家**投贊成**
- 理論上，自己進任務，達成遊戲目標的可能性越高，因此：【邏輯】
  - 不會沒有意義地**贊成沒有自己**的任務組合
  - 不會沒有意義地**反對有自己**的任務組合
- 反過來說：【邏輯】
  - 異常票通常是有意義的
  - 不論內黑或外白，通常都在反映對這個組合的看法

## 內黑

### 藍方

- 代表的意義：【經驗】
  - 反對這個組合整體
  - 反對這個組合內的某幾位玩家
  - 想反給這局的尾派派票，不想讓現在的尾派結構被洗掉
- 反對組合的代價：【經驗】
  - 一旦開了內黑，後面玩家最直觀的想法就是「這人不想跟某些人一起出任務」
  - 通常大家不會知道你反對誰，但會知道選了你，可能會再被你反對一次
  - 因此一般而言，你拿到的票會變少
  - 收益是：若後面的人認為你是好人，他派對的機會就上升了（不派你反對的組合）
- 反給尾派的延伸：【經驗】
  - 兩紅之後，常會看到場內的人一直打黑球
  - 這也是反給後面玩家或尾派的動作
  - 代表這些人認為後面還有好人，就算任務組合是全好，也不一定要馬上出任務

### 紅方

- 給場上錯誤的區間與視野：【經驗】
  - 組合內的所有好人都可能對你產生敵意
  - 如果騙到後面的好人，通常會誤導他們的派票
- 反給自己的尾派隊友。【經驗】

## 外白

### 藍方

- 代表的意義：【經驗】
  - 贊成這個組合整體
  - 不太可能只是贊成組合內的某幾位玩家
  - 反對目前的尾派，想要洗掉（改變尾家）
- 控尾派：【經驗】
  - 不論是當下的尾派、下一局的尾派，甚至是雙尾派，外白就是反對目前的尾派組合
  - 以 10 人局而言，就是「50 至少一壞」的意思（10 人局）
- 請小心使用：【經驗】
  - 一場遊戲的外白次數不會太多，一般是 3 次以下
  - 外白過多不具任何意義，只會被紅方利用

### 紅方

- 幫隊友衝出去，拿下任務失敗：【經驗】
  - 但通常衝刺完你也會壞掉
  - 因此使用時機一般在已經沒辦法進任務之後
  - 好人已經不認為你是好人、隊友也放棄你了：這時趕快發揮你剩下的作用
- 控尾派：【邏輯】
  - 假設兩紅，下一局最後幾個位置都是紅方
  - 就必須在下一局的前幾家讓任務通過，否則必為三紅

## 高風險高報酬

- 不管是內黑或外白，都代表釋放了一些視角和資訊。【邏輯】
  - 釋放資訊的同時，勢必要犧牲一些東西，例如：
    - 被選進任務的可能變小
    - 被誤解資訊
    - 梅林被刺的可能性變高（對尾家有敵意）
    - 紅方被抓的可能性變高（資訊太多，像能力者）
- 對紅方而言：【經驗】
  - 內黑外白不是必要的
  - 藍方永遠可能犯錯
- 對藍方而言：【經驗】
  - 除非認為「雙尾派」都是壞人，否則外白後任務失敗，資訊不一定更多
  - 內黑到全好組合、內黑反給壞人尾派，都會讓梅林很想殺人
- 10 人局能造成實質效果的外白，至少要兩顆（第一局則需要三顆）。（10 人局）【邏輯】
  - 如同前述，過度外白只會被利用
  - 還必須和隊友以及場上資訊互相配合
- 因此，若剛接觸這款遊戲、沒有一定的遊戲經驗，請不要隨意開外白。【經驗】
