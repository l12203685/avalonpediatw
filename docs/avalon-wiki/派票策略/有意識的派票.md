# 有意識的派票

## 派票之前

### 思考場上的資訊流

- 前面的人派了什麼：
  - 解讀場上的資訊流（客觀／旁觀視角）；
  - 是否有獨立資訊、雙重假設、邏輯一致性；
  - 是否有換位思考、跟隨場上共識、平衡局勢。
- 代入自己的身分與資訊：
  - 加入自己的身分與資訊後，再解讀場上的資訊流（主觀視角）；
  - 選出自己的組合，回頭檢查是否合理、是否突兀、是否難以解讀或容易造成誤解。

### 帶有意識

- 【經驗】不存在純隨機的派票：
  - 除了 1-1 的忠臣，每次派票都是有意識、有意義的；
  - 【邏輯】後面的派票會延續前面的派票展開（指邏輯上的展開）；
  - 以解題比喻：紅方負責布局出題，藍方負責解題破局。
- 什麼叫做帶有意識——清楚了解：
  - 自己任務選擇背後的前提；
  - 自己要選哪些人；
  - 自己為什麼做這樣的選擇；
  - 自己的選擇在表達什麼；
  - 這樣選擇後，希望達到的效果與目的。

## 派票之後

### 思考場上的資訊流

- 後面的人派了什麼：
  - 在你後面的玩家，有沒有根據你的派票做出反應；
  - 資訊交叉比對下，場上是否認同你的資訊。
- 代入自己的身分與資訊：
  - 後面的人是否誤解你的身分或陣營；
  - 後面的人是否「利用」你的資訊做誤導。

### 即時修正

- 每個動作之後都要思考：
  - 你的效果與目的是否達到；
  - 資訊是否正確傳遞、任務引導是否成功、場上是否認同你是好人；
  - 如果局勢不如預期，即時修正，想辦法走向你期望的結果。
- 隨機應變：
  - 派票到投黑白球並非連續動作；
  - 隨時因應場上的派票與黑白球應變；
  - 也可以「隨機變硬」（原文雙關語，意指視情況轉為強硬）。
